# قائمة القبول — Loomix مقابل المواصفة

حالة كل بند كما نعرفها اليوم. المصطلحات:

- **مُتحقَّق:** نُفِّذ في الكود، وشُغِّل فعليًا عبر HTTP أو سكربت، ونتيجته معروفة.
- **مُنفَّذ:** موجود في الكود، ولم يُشغَّل في هذه البيئة.
- **غير مُتحقَّق:** يعتمد على بيئة لا نملكها (متصفح حقيقي، نشر فعلي، مفاتيح خارجية).

> لا يوجد متصفح في بيئة البناء. كل «تحقّق» هنا يستند إلى استجابات HTTP، وHTML المُصيَّر،
> وفحوص قاعدة البيانات، واستدعاء إجراءات الخادم مباشرة. لا ندّعي أي فحص بصري.

## 1. الهوية والتصميم (§2)

| البند | الحالة | الدليل |
|---|---|---|
| RTL عربي افتراضي | مُتحقَّق | `<html lang="ar" dir="rtl">` على المسارات المفحوصة |
| ثيم داكن + لون تمييز واحد | مُنفَّذ | `brass-*` فقط في `app/globals.css` |
| خط عربي بأوزان متعددة | مُتحقَّق | Fontsource محلي؛ 10 ملفات woff2 تُحمَّل مسبقًا في كل صفحة |
| شبكة بوسترات متجاوبة | مُنفَّذ | `PosterGrid` بـ`sizes`؛ لم يُفحص بصريًا |
| أزرار/بطاقات/هياكل/فراغ/خطأ | مُتحقَّق جزئيًا | هياكل لكل قائمة؛ 404 مُصمَّم بكود 404 |
| حركات هادئة | مُنفَّذ | `prefers-reduced-motion` في `globals.css` |
| شعار أصلي (أيقونة + كامل) | مُتحقَّق | SVG واحد بنسختين، بلا معرّفات مكرّرة |

## 2. خريطة الموقع (§3)

كل المسارات موجودة: `/` · `/movies` · `/series` · `/anime` · `/latest` · `/trending` · `/top-rated` ·
`/most-viewed` · `/genre/[slug]` · `/year/[year]` · `/country/[code]` · `/search` · `/movie/[slug]` ·
`/series/[slug]` · `/series/[slug]/season/[n]` · `.../episode/[m]` · `/trailers` · `/person/[slug]` ·
`/watchlist` · `/login` · `/register` · `/profile` · `/privacy-policy` · `/terms` · `/dmca` · `/contact` · 404.

- **مُتحقَّق:** زحف 220 رابطًا من `sitemap.xml` → كلها 200، وصفر روابط مكسورة.
- **404 حقيقي:** `/series/<مجموعة>`, `/anime/<مجموعة>`, `/movie/<غير موجود>`, موسم/حلقة/شخص/تصنيف/سنة
  غير موجودة، `/messages` → كلها 404 لا 200.
- **`/most-viewed`** لا يعرض شيئًا قبل وجود مشاهدات حقيقية (`views_count >= 1`) ويشرح السبب.
- **مُتحقَّق (عدّاد المشاهدات):** `POST /api/views` يعيد 200، والرابع في الساعة لنفس IP+العمل يعيد 429،
  والجسم المشوّه 400، والمعرّف المجهول 404. بعد أول مشاهدة ظهر العمل في `/most-viewed`، وبعد تصفير
  العدّاد عادت الحالة الفارغة — أي أن القائمة تقرأ العدّاد فعليًا لا شيئًا مُعدًّا مسبقًا.

## 3. سلامة البيانات (§4)

| القاعدة | الحالة |
|---|---|
| لا تقييم بلا مصدر | مُتحقَّق (نموذج اللوحة يرفض، والواجهة وJSON-LD يُخفيان) |
| لا «N/A» — الحقول الغائبة تُخفى | مُنفَّذ |
| تفرّد (اسم عربي + سنة) | مُتحقَّق في الإجراء والاستيراد المجزأ |
| تفرّد (موسم + رقم) | مُنفَّذ بقيد فريد |
| Trending بترتيب يدوي أو عدّاد حقيقي | مُنفَّذ؛ كل `views_count` تبدأ من 0 |
| بيانات تجريبية موسومة | مُنفَّذ: `isDemo` + لافتة + شارة |

## 4. اللوحة (§10) — 25 مسارًا

| الوظيفة | الحالة |
|---|---|
| دخول/خروج وإدارة الجلسة | **مُتحقَّق**: 303 بعد الدخول، كوكي `HttpOnly; Secure; SameSite=Lax`، صلاحية 12 ساعة للإدارة |
| RBAC | **مُتحقَّق**: مشاهد على `/admin` → 307 إلى `/?forbidden=admin`؛ رفع ملفات كـمشاهد → 403؛ مجهول → 401 |
| إنشاء عمل | **مُتحقَّق** (POST حقيقي ← 303 ← ظهور في اللوحة والواجهة والخريطة) |
| تعديل عمل | **مُتحقَّق**: حفظ الحقل، ظهوره في اللوحة وفي صفحة العمل فورًا (إبطال الكاش)، ثم استرجاع |
| حذف عمل | **مُتحقَّق**: اختفى من اللوحة، صفحته والإدارة 404، وسجل تدقيق `TITLE_DELETE` |
| استيراد CSV/JSON مجزّأ | **مُتحقَّق**: تحليل ← تقرير أخطاء عربي لكل صف ← دفعات 10 صفوف ← منع التكرار ← التكرار لا يعيد المعالجة |
| المواسم والحلقات | **مُتحقَّق**: إنشاء/تعديل موسم، رفض الرقم المكرر برسالة عربية، إنشاء حلقة، رفض الرقم المكرر، إضافة دفعة 3 حلقات كمسودات، إعادة الدفعة لا تكرّرها |
| الأشخاص والتصنيفات | **مُتحقَّق**: إنشاء شخص وتعديله وحذفه؛ إنشاء تصنيف وحذفه مع منع الحذف قبل إعادة التصنيف |
| التريلرات | **مُتحقَّق**: إضافة، تعيين الأساسي (تبدّل الفيديو في صفحة العمل فورًا)، حذف؛ فحص الصحة بلا شبكة يُبقي الحالة «لم يُفحص» برسالة صريحة |
| التحديث الجماعي | **مُتحقَّق**: حماية التعديل اليدوي تُخطّي الأعمال المحمية، والتقرير يعرض قبل→بعد، والسبب في سجل العمليات |
| أقسام الرئيسية | **مُتحقَّق**: إخفاء قسم يزيله من الصفحة فورًا، وإرجاعه يعيده، والترتيب يتغيّر بالحركة |
| قوائم الترند/اختيارات المحرر | **مُتحقَّق**: إضافة عمل، منع التكرار برسالة، التثبيت (pinned) يرفعه للأول، الحذف يُرجع العدد |
| المستخدمون والأدوار | **مُتحقَّق**: إنشاء حساب، رفض بريد مكرر، رفض كلمة مرور قصيرة، تغيير الدور، تعطيل/تفعيل، حذف |
| إعدادات SEO | **مُتحقَّق**: إطفاء فهرسة الأعمال يضيف `noindex` على صفحة العمل فورًا، وإرجاعه يزيله |
| التنقل والتذييل | **مُتحقَّق**: تغيير تسمية يظهر في الرأس مباشرة، الروابط الخارجية مرفوضة برسالة عربية |
| نسخ احتياطي واستعادة | **مُتحقَّق** (18 جدولًا / 547 صفًا ذهابًا وعودة) |
| رفع الصور | **مُتحقَّق**: WebP صالح ← 200 مع نسختين 400/900؛ نص متنكّر كـPNG ← 415 بفحص البايتات؛ أكبر من 6MB ← 413 |
| صندوق الرسائل وDMCA | **مُتحقَّق**: 5 رسائل ناجحة ثم حجب، حقل المصيدة لا يُدرج، والرسائل تظهر في اللوحة |
| سجل التدقيق | **مُتحقَّق**: صفوف الدخول/التعديل/الحذف/الاستيراد/الرسائل |
| المصادر الخارجية (API) | معطّلة عن قصد؛ الصفحة تُظهر وجود المفتاح لا قيمته |
| الإعلانات | غير مبنية (خارج النطاق حسب المواصفة) |
| ترتيب الأقسام والرائج بالسحب | **المنطق مُتحقَّق** (أزرار الحركة تعمل)، والسحب نفسه غير مُتحقَّق (يحتاج متصفحًا) |

**بلا JavaScript:** نماذج الإضافة والتعديل **تعمل** — تحقّقنا فعليًا بإرسال
`multipart/form-data` يحتوي حقول `$ACTION_*` كما تصدّرها الصفحة (إنشاء عمل ثم تعديل حقل ورؤيته
في الواجهة). ما يبقى بحاجة إلى JS هو الإجراءات السريعة في صفوف القوائم (حذف/نشر)، والسحب
والترتيب، واختيار التصنيفات والأشخاص داخل نموذج العمل. شريط `<noscript>` يشرح هذا الفرق.

## 5. الأمان (§11)

- bcrypt (12 جولة) وجلسات عشوائية 32 بايت مُخزَّنة مُجزَّأة — مُتحقَّق.
- حدود المعدل: تسجيل الدخول (10/10د لكل IP)، التواصل (5/ساعة)، المشاهدات (3/ساعة لكل IP+عمل)،
  والبحث — مُتحقَّق بصدّ فعلي (429 أو رسالة حجب).
- حقل المصيدة في نموذج التواصل — مُتحقَّق (ردّ نجاح كاذب بلا إدراج).
- CSP + HSTS + `X-Frame-Options` + `Referrer-Policy` + `Permissions-Policy` — مُتحقَّق بالاستجابة.
- أسرار الخادم لا تظهر في أي صفحة؛ بيانات الدخول التجريبية تُعرض فقط عند `SHOW_DEMO_CREDENTIALS=1`.
- سجل التدقيق للقراءة فقط من الواجهة.

## 6. البحث (§12)

- الاسم العربي والأصلي وفلاتر النوع والتصنيف والسنة والدولة — مُنفَّذ.
- مطابقة جزئية وتطبيع (همزة/تاء مربوطة/هاء) وإسقاط «ال» — **مُتحقَّق**: `ظل` 2، `الظل` 2،
  `ليله` 1، `القاهره` 1، `الليلة` 1.
- ترتيب وفلاتر مركّبة وقيم غير صالحة تعود للافتراضي — مُتحقَّق.
- حالة فراغ صريحة — مُتحقَّق. حالة «صفحة خارج النطاق» لها نص خاص وزر «الصفحة الأولى».

## 7. SEO (§15)

- عنوان ووصف فريدان، canonical، `sitemap.xml` (220 رابطًا كلها 200، 37 `lastmod`)،
  `robots.txt` يمنع `/admin` و`/search` — مُتحقَّق.
- Schema.org من حقول حقيقية: `datePublished` بتاريخ كامل فقط، و`aggregateRating` مشروط بمصدر — مُتحقَّق.
- `Organization` + `WebSite` + `SearchAction` على مستوى الموقع في كل الصفحات (JSON صالح مُختبَر على 4 مسارات) — مُتحقَّق.
- إعدادات الفهرسة (`seo_index_*`) تعمل فعليًا: إطفاؤها يضيف `noindex` على صفحات العمل/السنة/الدولة — مُتحقَّق.
- OG/Twitter: لكل عمل صورة مشاركة **مرسومة على الخادم** (`opengraph-image.tsx` لكل مسار أفلام/مسلسلات/أنمي)
  بمقاس 1200×630 وبوستر العمل والعنوان والتصنيفات والسنة، وصورة العلامة كبديل للروابط غير الموجودة.
  **مُتحقَّق:** 200 + `image/png` لكل المسارات الثلاثة + البديل، والحجم 90–200KB، والاستجابة 0.13–0.5 ثانية.
  ملاحظة تقنية موثّقة: خط Noto Kufi غير صالح للرسم (GSUB format 3 غير مدعوم في Satori) فتُستخدم Plex Arabic.
- صور OG للصفحات القائمة (تصنيف/سنة/دولة/شخص/تريلرات) تستخدم صورة العلامة الافتراضية.

## 8. الأداء والإتاحة (§16)

- ضغط النقل فعّال: صفحة الرئيسية 315KB HTML ← 39KB gzip — **مُتحقَّق**.
- أصول `/_next/static/*` بـ`immutable, max-age=31536000` — مُتحقَّق.
- محسّن الصور يخدم WebP/AVIF لكل عرض مطلوب؛ `deviceSizes` مسقوفة عند 1920 بعد أن كان
  الأقصى 3840 يُكبّر أصلًا بعرض 1584 بلا فائدة — مُتحقَّق.
- تباين WCAG AA حسابيًا: أدنى نسبة 4.92:1 (ink-500) — مُتحقَّق.
- `h1` واحد، بلا معرّفات مكرّرة، تسميات نماذج، أزرار أيقونية مسمّاة، skip link — مُتحقَّق.
- **غير مُتحقَّق:** قارئ شاشة، تنقّل لوحة مفاتيح، أي حكم بصري.

## 9. ما لم يُتحقَّق إطلاقًا

1. نشر فعلي (Vercel / Postgres مُدارة / تخزين كائنات).
2. مزامنة TMDB أو أي مصدر خارجي بمفتاح حقيقي.
3. العمل البصري: التناسق، التراكب، سلوك الهاتف.
4. السحب والإفلات بالماوس/اللمس (أزرار الترتيب تعمل، والسحب نفسه غير مُختبر).
5. الإجراءات السريعة في صفوف اللوحة بلا JavaScript (نماذج الإضافة/التعديل تعمل، أما أزرار الحذف والنشر فتحتاج JS).

## 10. جاهزية النشر — ما تحقّق فعليًا

| البند | النتيجة |
|---|---|
| `npm run preflight` (تطوير) | 0 خطأ · 4 تحذيرات · كود خروج 0 |
| `npm run preflight -- --prod` | 5 أخطاء (PGlite، localhost، بيانات عرض، كلمتا مرور افتراضيتان) · كود خروج 1 |
| `db:seed` على قاعدة شبكية | مرفوض برسالة عربية · كود خروج 1 |
| `db:seed` في `NODE_ENV=production` | مرفوض · كود خروج 1 |
| `db:seed` مع `SEED_DEMO=1` | يتجاوز الحارس ويحاول التنفيذ |
| `admin:password` (مسار تأهيل الإنتاج) | أنشأ مديرًا، والدخول به عبر HTTP نجح ثم حُذف |
| `npm run check:data` | كل الفحوص سليمة · كود خروج 0 |
| `npm run smoke -- http://localhost:3000` | 0 خطأ · تحذير واحد (http بلا HSTS) |
| `npm run smoke -- … --prod` | يكتشف كلمة المرور التجريبية في `/login` · كود خروج 1 |
| `npm run smoke -- … --crawl` | 40 رابطًا من الخريطة كلها تعمل |
| `npm run smoke -- <عنوان غير متاح>` | خطأ وصول · كود خروج 1 |

**غير مُتحقَّق:** النشر الفعلي وحصص المنصة، والتخزين الدائم للصور على Vercel (يعمل محليًا فقط —
`preflight --prod` يحذّر منه).

## 11. أخطاء وُجدت وأُصلحت في هذه الجولة

1. **أعداد 0 في اللوحة**: استعلامات `count(*)` الفرعية في `lib/admin-queries.ts` كانت تُصدَّر
   بأعمدة غير مؤهّلة، فصار `"season_id" = "id"` يُقارن عمودَي الجدول الداخلي → كل الأعداد 0
   (حلقات المواسم، أعمال التصنيفات، أعمال الأشخاص، جلسات المستخدمين). صُحّحت بأسماء مؤهَّلة.
2. **رسائل التكرار العامة**: `saveSeasonAction`/`saveEpisodeAction` كانت تفحص `error.message`
   فقط، وDrizzle يضع خطأ Postgres 23505 في `cause` → كان يُعرض «تعذّر الحفظ» بدل
   «يوجد موسم بهذا الرقم». أُضيف `lib/db-errors.ts` ويفحص سلسلة `cause`.
