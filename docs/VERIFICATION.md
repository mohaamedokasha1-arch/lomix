# سجل التحقّق — Loomix

هذا الملف يجمع **ما شُغِّل فعلًا** ونتيجته، في مكان واحد. لا يحلّ محل `docs/ACCEPTANCE.md`
(الذي يربط كل بند في المواصفة بحالته)، بل يوثّق الجولة الأخيرة كاملة بأرقامها وأدواتها.

> **البيئة:** بناء `next build` + `next start` على `http://localhost:3000`، قاعدة PGlite محلية
> بالبيانات التجريبية (24 عملًا). **لا متصفح في بيئة البناء**، فكل قياس هنا من استجابات HTTP،
> وHTML المُصيَّر، واستعلامات قاعدة البيانات. لا ادّعاء بصري ولا قياس LCP ميداني.

## 2) تفصيل النتائج

### 2.1 المسارات والفهرسة

- `sitemap.xml` يضم **220** رابطًا، كلها على النطاق نفسه، وكلها تُعيد `200`. لا رابط مكسور.
- كل صفحة: `<title>` واحد غير مكرّر، `meta description` غير مكرّرة، `canonical` مطلق، و`h1` واحد.
- أوصاف الصفحات **220/220** داخل النطاق المفيد **70–165** حرفًا: الوسيط 132، الأقصر 70، الأطول 160،
  وبلا وصف مكرّر بين صفحتين. **مُتحقَّق:** `npm run seo:audit -- http://localhost:3000` (0 خطأ · 0 تحذير).
- المسارات غير الموجودة: **404** حقيقي + `noindex` (مغطّى في `smoke`).

### 2.2 البيانات المنظّمة (JSON-LD)

- 220 صفحة تحمل JSON-LD على الأقل؛ **448** كتلة إجمالًا، كلها تُحلَّل كـJSON صالح.
- الأنواع: `Movie` 12 · `TVSeries` 12 · `Person` 78 · `BreadcrumbList` 102 · `ItemList`/`CollectionPage`
  و`Organization`/`WebSite` في قوالب الموقع.
- `ItemList.numberOfItems` يطابق عدد العناصر فعليًا في **كل** الصفحات (0 اختلاف).
- لا `aggregateRating` بلا مصدر مسجّل (0 مخالفة)، و`/most-viewed` لا يُصدر قائمة فارغة.

### 2.3 الإتاحة (فحص آلي للبنية)

| النطاق | الصفحات | النتيجة |
|---|---|---|
| الواجهة | 22 (رئيسية، قوائم، تفاصيل، شخص، قانونية، دخول/تسجيل) | 0 ملاحظة |
| اللوحة | 25 (كل صفحات الإدارة بما فيها التفاصيل والحذف والمواسم) | 0 ملاحظة |

الفحص يغطي: `h1` واحد، `img alt`، معرّفات غير مكرّرة، روابط/أزرار بنص، وكل حقل إدخال له تسمية
(`label[for]` أو `label` محيط أو `aria-label`). **الاستثناء الوحيد المقصود:** حقول `type="file"`
داخل حاوية `display:none` (منتقي الملفات المخفي في محرّر الوسائط) — ليست عيبًا لأنها غير مرئية
ولا تُركَّز بلوحة المفاتيح، والبديل المرئي هو حقل المسار المسمّى بـ`aria-label`.

**غير مفحوص:** التباين الفعلي في متصفح، ترتيب التركيز، قارئ شاشة، سلوك السحب والإفلات.

### 2.5 سياسة المحتوى والحقوق

على 8 صفحات (رئيسية، أفلام، تريلرات، بحث، فيلم، مسلسل، أنمي، شخص):

- لا عبارة «مشاهدة الآن» أو «شاهد الفيلم» أو `watch now` — التريلر فقط، وباسمه الصريح.
- لا `N/A` ولا «غير متوفر» — الحقول الغائبة تُخفى.
- لا `<video>` إطلاقًا، ولا `<iframe>` في HTML الأولي (التضمين يُحمَّل عند طلب المستخدم).
- نصوص الصفحات تذكر صراحة أن الموقع لا يوفّر مشاهدة العمل كاملًا.

### 2.7 الوظائف (e2e)

### 2.9 حدود الأخطاء وصفحات 404

| الفحص | النتيجة |
|---|---|
| `load` لمسار يرمي استثناءً (مؤقت، أُزيل) | 500 · لا نص استثناء ولا stack في الاستجابة |
| تسجيل حدّي الخطأ في حِزَم العميل | `app/(site)/error-*.js` و`app/(admin)/error-*.js` موجودان، والنص العربي بداخلهما |
| `page_client-reference-manifest` لكل قسم | يشير إلى `app/(site)/error` و`app/(admin)/error` — أي أن الحدّ مربوط بالشجرة |
| `/admin/titles/<معرّف غير موجود>` | **404** + نص «هذا العنصر غير موجود» + روابط داخل اللوحة |
| `/admin/nonexistent` | 404 (يستخدم 404 العام لأن المسار غير مطابق أصلًا) |

### 2.10 أوصاف SEO

قبل هذه الدفعة كانت **184** صفحة من 220 بوصف أقصر من 70 حرفًا (أقصرها 17 حرفًا)، معظمها صفحات
مولّدة تلقائيًا. بُنيت الأوصاف الآن من بيانات مسجّلة فعلًا، بلا اختراع أرقام:

| النوع | الصيغة | قبل → بعد (حرفًا) |
|---|---|---|
| شخص (78) | عدد الأعمال + مجالها + المدى الزمني من سنوات الإصدار المسجّلة | 26–30 → **110–115** |
| موسم (13) | عدد الحلقات + أول وآخر تاريخ عرض + مجموع المدّة الساعات/الدقائق | 24–40 → **112–151** |
| حلقة (76) | رقم الحلقة واسمها + الموسم + تاريخ العرض + المدّة | 22–37 → **133–157** |
| تصنيف (16) | الفلاتر المتاحة فعلًا (النوع/السنة/البلد) + ما تعرضه الصفحة | 56–61 → **129–130** |
| قانوني وتواصل (3) | عناوين الأقسام الموجودة في الصفحة نفسها + وقت الرد المعلن | 50–65 → **145–152** |

- الأوصاف الطويلة تُبنى بترتيب أولوية: السيرة إن كانت ≥70 حرفًا، وإلا الصيغة أعلاه؛ ولا يُقتطع
  نص إلا عند تجاوز 165 حرفًا (بسقف 158 + «…»).
- صيغ العدد العربية مضبوطة (`arabicCount`): «عمل واحد / عملان / 5 أعمال / 13 عملًا»،
  و«4 ساعات و5 دقائق» لا «4 ساعة و5 دقيقة».
- إذا وقعت كل حلقات الموسم في الشهر نفسه يُقال «عُرضت في أغسطس 2022» لا «بين أغسطس وأغسطس».
- **بوابة قابلة للتكرار:** `scripts/seo-audit.ts` يزحف الخريطة كاملة (220 رابطًا) ويخرج بكود 1 عند
  وصف ناقص/قصير/مكرّر. اختُبر سلبيًا: `--min=140` → خطأ واحد و«151 وصفًا أقصر من 140» وكود خروج **1**؛
  `--max=100` → تحذير فقط وكود خروج **0**.

## 3) ما لم يُتحقَّق (ولا يُقدَّم كضمان)

1. **نشر فعلي** على Vercel مع Postgres مُدار — يحتاج حسابًا ونطاقًا ومفاتيح.
2. **Vercel Blob**: مسار الرفع مكتوب ومربوط، لكن جلبًا ناجحًا من مخزن حقيقي لم يُجرَّب (لا توكن).
3. **المتصفح**: التباين المرئي، ترتيب التركيز، السحب والإفلات، وسلوك الهاتف، ورسم حدود
   الأخطاء (`error.tsx`) بعد التحميل — الحدّ نفسه مربوط ومُحزَّم، لكن شكله النهائي لم يُرَ.
4. **قياس LCP/CLS ميدانيًا** — أرقام الأداء أعلاه من HTML وتقرير البناء، لا من Web Vitals.
5. **مصادر خارجية** (TMDB): مزامنة بمفتاح حقيقي لم تُجرَّب، والميزة معطّلة عن قصد.
6. **الحصص الفعلية** على Vercel/Neon تحت حمل حقيقي.

## 4) كيف تعيد التشغيل

```bash
# يتطلب خادمًا يعمل على :3000
npm run smoke -- http://localhost:3000          # فحوص الدخان + السياسة + الأداء + JSON-LD
npm run seo:audit -- http://localhost:3000      # أوصاف كل صفحات sitemap (طول + تكرار)
npm run e2e                                     # 21 خطوة وظيفية وأمنية

# لا يحتاج خادمًا (لكن يحتاج قاعدة غير مستخدمة من عملية أخرى)
npm run check:data                              # سلامة البيانات
npm run check:art                               # مصادر صور المشاركة (15 حالة)
npm run preflight                               # جاهزية النشر
```

الفحوص التي لا تعيش في المستودع (تحليل HTML الكامل وa11y) تُعاد بأدوات خارجية؛ نتائجها هنا
موثّقة بتواريخها، و`smoke` يغطي النسخة الآلية القابلة للتكرار منها.
