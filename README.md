# Loomix · لوميكس

منصة عربية لاكتشاف الأفلام والمسلسلات والأنمي: بيانات منظّمة، تريلرات رسمية مُضمَّنة، وتجربة سينمائية هادئة.
**Loomix لا يستضيف أي فيلم أو مسلسل كامل.** لا يوجد زر «مشاهدة الآن» لأنه لا يوجد مصدر بث مرخّص —
كل ما نقدّمه هو الاستكشاف والتريلر الرسمي.

---

## ما يميّز هذه النسخة

- **عربي أولًا (RTL)** بخطوط محلية (Kufi للعناوين، Plex للنص، Manrope للأرقام اللاتينية) بلا طلبات خارجية للخطوط.
- **مبدأ الصدق في البيانات:** التقييم لا يظهر إلا بقيمة **ومصدر** مسجّلين. الحقول الغائبة تُخفى ولا تُملأ بـ«N/A».
  «الترند» ترتيب تحريري معلن، و«الأكثر مشاهدة» عدّاد حقيقي مع توضيح حدوده.
- **تريلر ≠ مشاهد.** زر التريلر يفتح مشغّلًا مضغوطًا من يوتيوب (`youtube-nocookie`)، ولا توجد أي واجهة تشبه المشاهدة الكاملة.
- **لوحة تحكم كاملة** بصلاحيات على الخادم (ADMIN / EDITOR / VIEWER): أعمال، مواسم وحلقات، تريلرات، تصنيفات، أشخاص،
  مكتبة وسائط، ترتيب الرئيسية والقوائم، **إدارة التنقل والتذييل**، استيراد CSV/JSON بتقرير أخطاء ودفعات،
  **تحديث جماعي بسجل تغييرات**، **حالة مصادر البيانات**، رسائل وDMCA، مستخدمون، إعدادات، SEO،
  نسخ احتياطي/استعادة، وسجل عمليات ثابت.
- **قاعدة بيانات علائقية حقيقية** (Postgres في الإنتاج، PGlite محليًا) مع 23 جدولًا وقيود تفرّد.
- **بحث عربي مُطبَّع** (همزات، تاء مربوطة، تشكيل) يطابق الاسم العربي والأصلي.

> **البيانات الحالية تجريبية.** 24 عملًا fictional بالكامل، مصوّرة ببرنامج توليد فني أصلي، وموسومة بـ`isDemo`.
> عدّادات المشاهدات تبدأ من صفر ولا تُملأ تجريبيًا: «الأكثر مشاهدة» تظهر فارغة حتى أول زيارة حقيقية.
> التريلرات التجريبية تحمل معرّفات `demo-*` ولا تشغّل فيديو خارجيًا. لا يوجد أي محتوى أو تصميم منسوخ من موقع آخر.

## التشغيل محليًا

```bash
npm ci
cp .env.example .env          # ثم عدّل القيم

npm run db:migrate            # إنشاء الجداول
npm run db:seed               # 24 عملًا تجريبيًا + حسابات
npm run dev                   # http://localhost:3000
```

الحسابات التجريبية (غيّرها فورًا قبل أي نشر):

| الدور | البريد | كلمة المرور |
|---|---|---|
| مدير | `admin@loomix.tv` | `Loomix@2026` |
| محرر | `editor@loomix.tv` | `Editor@2026` |
| مشاهد | `viewer@loomix.tv` | `Viewer@2026` |

> لا تظهر هذه البيانات في صفحة الدخول إلا إذا فعّلت `SHOW_DEMO_CREDENTIALS="1"` في `.env`.
> الافتراضي هو الإخفاء التام: كشفها في الإنتاج يعني تسليم لوحة التحكم لأي زائر.

`VIEWER` لا يدخل لوحة التحكم أصلًا (التحقق في `app/(admin)/layout.tsx`)، وكل إجراء خادمي يُعيد فحص الدور.

### أوامر مفيدة

```bash
npm run typecheck    # TypeScript صارم، بلا أخطاء
npm run build        # بناء إنتاجي
npm run check:data   # فحص سلامة البيانات (تقييم بلا مصدر، تكرار، صفوف مكسورة…)
npm run verify       # typecheck + check:data معًا
npm run preflight    # جاهزية النشر (-- --prod يتشدّد) — يخرج بكود 1 عند وجود خطأ
npm run smoke -- https://your-domain.com --prod --crawl   # فحص دخان بعد النشر (HTTP فقط)
npm run db:reset     # مسح + إعادة تهيئة كاملة (محليًا)
npm run admin:password -- admin@example.com "كلمة-مرور-قوية"   # يُنشئ/يحدّث مديرًا ويُبطل جلساته
npm run backup       # نسخة JSON في backups/ (أو -- --out /path/file.json)
npm run art:generate # إعادة توليد الأعمال الفنية الأصلية (resvg + sharp)
```

> بعد `db:reset` تكون معرّفات الصفوف جديدة. `unstable_cache` يبقى في `.next/cache` بين عمليات التشغيل،
> لذا امسح الكاش (`rm -rf .next/cache`) قبل `npm run build` إن ظهرت روابط أو بيانات قديمة في العرض المحلي.

> `check:data` يخرج بكود 1 عند وجود خطأ (تقييم بلا مصدر، تكرار اسم+سنة، تريلر بمعرّف غير صالح…)،
> ويمكن وصله بأي CI. لا يعدّل بيانات، ويطبع ملخصًا للحالة.

## الأمان

- كلمات المرور: bcrypt (12 rounds). الجلسات: توكن عشوائي 32 بايت، يُخزَّن **مُجزَّأ** SHA-256، وكوكي `httpOnly` + `sameSite=lax`.
- القفل: 5 محاولات فاشلة → قفل 15 دقيقة، وحدّ معدّل على تسجيل الدخول والرسائل والمشاهدات — كلها في قاعدة البيانات.
- كل إجراء في اللوحة يبدأ بـ`requireStaff()` أو `requireAdmin()` على الخادم؛ إخفاء الأزرار ليس حماية.
- رفع الصور: فحص النوع من البايتات الأولى (magic bytes)، حد 6MB، إعادة ترميز بـ`sharp` إلى WebP، ورفض غير الصور.
- الاستيراد: تحقق صفّي كامل قبل أي إدراج، ثم دفعات 10 صفوف، والحالة في `import_jobs`.
- المفاتيح السرية تُقرأ على الخادم فقط. `.env` مستثنى، و`.env.example` وحده يُرفع.

## محتوى تجريبي: كيف تتخلص منه

```bash
npm run db:reset     # يمسح كل شيء ويعيد البيانات التجريبية

```

أو احذف `db/seed.ts` من سكربت التهيئة ثم:

```bash
npm run db:migrate && npm run admin:password -- you@example.com "كلمة-قوية"
```

شارة «تجريبي» تظهر تلقائيًا على أي عمل `isDemo = true`، ويمكن إخفاء الشريط العام من إعدادات الموقع
(`show_demo_notice`) — لكن الوسم على العمل نفسه يبقى حتى يستبدله محتوى حقيقي.

## الحقوق

التريلرات تُضمَّن من القنوات الرسمية فقط، ولا تُعاد استضافتها. الصور الفنية في هذه النسخة أصلية ومولّدة برمجيًا.
لإشعارات الحقوق: صفحة `/dmca` وصندوق `DMCA` في اللوحة. التفاصيل في `docs/CONTENT-POLICY.md`.

## حالة التحقق

- `npm run typecheck` — بلا أخطاء.
- `npm run build` — ناجح، كل المسارات مبنية.
- **ما لم يُختبر:** النشر على Vercel، حدود الحصص، والاتصال بمصادر خارجية (الشبكة محجوبة جزئيًا في بيئة البناء).
  هذه النقاط موثّقة كغير مُتحقَّق منها في `docs/DEPLOYMENT.md`، ولا تُقدَّم كضمانات.
